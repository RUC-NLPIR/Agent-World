# YouTube Vision — local MCP environment

YouTube Vision stores ingested YouTube video metadata plus derived artifacts generated by Gemini (summaries, Q&A answers, and key moments). The main workflow is: a client references a video, the system ensures the video is ingested/transcribed, runs model jobs to generate artifacts, and returns cached results; it also exposes a catalog of supported Gemini models used for generation.

Repository: https://github.com/minbang930/Youtube-Vision-MCP
Homepage: https://smithery.ai/server/@minbang930/youtube-vision-mcp

## Datastore

- `videos.json` — Canonical YouTube video records tracked by the service, including identifiers, ingestion state, and pointers to fetched assets needed for downstream generation. (19 rows; fields: ['id', 'youtube_video_id', 'source_url', 'title', 'channel_name', 'published_at', 'duration_seconds', 'language_code', 'transcript_text', 'transcript_source', 'transcript_updated_at', 'status', 'last_error', 'created_at', 'updated_at'])
  - lifecycle `status`: ['new', 'ingesting', 'ready', 'failed', 'deleted']
  - constraint: unique(youtube_video_id)
  - constraint: duration_seconds is null OR duration_seconds >= 0
  - constraint: transcript_source != 'none' implies transcript_text is not null
  - constraint: status = 'ready' implies transcript_text is not null
- `model_catalog.json` — Catalog of Gemini model identifiers known to support generateContent, used by the service for selection and auditing. (18 rows; fields: ['id', 'provider', 'model_name', 'supports_generate_content', 'max_output_tokens', 'is_default', 'status', 'created_at', 'updated_at'])
  - lifecycle `status`: ['active', 'deprecated', 'disabled']
  - constraint: unique(provider, model_name)
  - constraint: is_default = true implies status = 'active'
  - constraint: at most one row where is_default = true and status = 'active'
- `generation_jobs.json` — Asynchronous generation requests (summaries, Q&A, key moments) executed against a specific model and input snapshot of a video transcript. (18 rows; fields: ['id', 'video_id', 'job_type', 'question_text', 'prompt_version', 'model_id', 'input_transcript_hash', 'temperature', 'max_output_tokens', 'status', 'started_at', 'finished_at', 'error_message', 'created_at', 'updated_at'])
  - lifecycle `status`: ['queued', 'running', 'succeeded', 'failed', 'cancelled']
  - constraint: question_text is not null iff job_type = 'qa_answer'
  - constraint: temperature is null OR (temperature >= 0.0 AND temperature <= 2.0)
  - constraint: max_output_tokens is null OR (max_output_tokens >= 1 AND max_output_tokens <= 32768)
  - constraint: finished_at is null OR started_at is not null
- `video_artifacts.json` — Materialized outputs for summarize, ask, and key moments. This is the read-optimized cache returned to API callers. (18 rows; fields: ['id', 'video_id', 'job_id', 'artifact_type', 'question_text', 'model_id', 'prompt_version', 'input_transcript_hash', 'content_text', 'key_moments', 'status', 'created_at', 'updated_at'])
  - lifecycle `status`: ['active', 'superseded', 'deleted']
  - constraint: question_text is not null iff artifact_type = 'qa_answer'
  - constraint: content_text is not null iff artifact_type in ('summary','qa_answer')
  - constraint: key_moments is not null iff artifact_type = 'key_moments'
  - constraint: unique(video_id, artifact_type, coalesce(question_text,''), prompt_version, model_id, input_transcript_hash, status) where status='active'

## Business rules enforced by the tools

- All three read-like tools (summarize_youtube_video, ask_about_youtube_video, extract_key_moments) must resolve a YouTube video to a videos row by youtube_video_id (parsed from URL or provided context) and may create it if missing with status='new'.
- Before creating a generation_jobs row, the video must be in status='ready'; otherwise the system must transition videos.status to 'ingesting' and attempt transcript acquisition, ending in 'ready' with transcript_text populated or 'failed' with last_error set.
- summarize_youtube_video must return an active video_artifacts row where artifact_type='summary' matching the latest input_transcript_hash (and service default model/prompt_version); if not present, enqueue a generation_jobs row of job_type='summary' and on success upsert the artifact and supersede any prior active summary artifacts for the same (video_id, model_id, prompt_version) with different transcript_hash.
- ask_about_youtube_video must return an active video_artifacts row where artifact_type='qa_answer' and question_text matches the normalized question (empty/null treated as a request for general description). If no question was provided, the service must store question_text as null and generate a general description answer.
- extract_key_moments must return an active video_artifacts row where artifact_type='key_moments' matching the latest input_transcript_hash; if not present it must enqueue a generation_jobs row of job_type='key_moments' and store moments into video_artifacts.key_moments as structured data.
- list_supported_models must return model_catalog rows where provider='google_gemini' and supports_generate_content=true and status in ('active','deprecated'); it must not return status='disabled' models.
- A generation_jobs row may only transition status according to the declared transitions; setting status='succeeded' requires finished_at not null and error_message null; setting status='failed' requires finished_at not null and error_message not null.
- Deleting a video (videos.status='deleted') must cascade to mark related video_artifacts.status='deleted' and prevent new generation_jobs from being queued for that video.
- Service must enforce cache correctness: artifacts are only reusable when (video_id, artifact_type, question_text, prompt_version, model_id, input_transcript_hash) match; otherwise a new job must be created.
