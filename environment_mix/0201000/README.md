# AtlasSeed Data Hub

AtlasSeed Data Hub provides small data-loading and lookup utilities for common demo datasets like countries, iris measurements, and sales transactions.

## Datastore

### `countries.json` — list of 241 records
Holds a catalog of country records with names, flags, ISO codes, and dial codes so the service can support country lookups and listings.

- `name` — string
- `flag` — string
- `code` — string
- `dial_code` — string
